# Login UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the Portfoi logo above the login card, increase its size, constrain the card to form-only content, raise input/button touch targets to 44px, add autocomplete attributes, and replace plain-text error/success messages with styled inline banners.

**Architecture:** All changes are in two files — `src/components/Login.js` (JSX/logic) and `index.html` (CSS). No new components, no new state, no new Supabase calls. The existing `isReg` state drives the `autocomplete` switch for the password field.

**Tech Stack:** React 18 UMD + Babel Standalone (browser-only, no build step). Local dev: `npx serve .` → http://localhost:3000. After any edit run `npm run check:babel` to catch JSX parse errors.

### Task 3: Add autocomplete attributes

**Files:**
- Modify: `src/components/Login.js`

- [ ] **Step 1: Add autocomplete to email input**

Find:
```jsx
<input type="email" value={email} onChange={e=>setEmail(e.target.value)} placeholder="ornek@mail.com" onKeyDown={e=>e.key==="Enter"&&submit()}/>
```

Replace with:
```jsx
<input type="email" autoComplete="email" value={email} onChange={e=>setEmail(e.target.value)} placeholder="ornek@mail.com" onKeyDown={e=>e.key==="Enter"&&submit()}/>
```

- [ ] **Step 2: Add autocomplete to password input**

Find:
```jsx
<input type="password" value={pw} onChange={e=>setPw(e.target.value)} placeholder="••••••••" onKeyDown={e=>e.key==="Enter"&&submit()}/>
```

Replace with:
```jsx
<input type="password" autoComplete={isReg?"new-password":"current-password"} value={pw} onChange={e=>setPw(e.target.value)} placeholder="••••••••" onKeyDown={e=>e.key==="Enter"&&submit()}/>
```

`isReg` is already in scope — no new state needed. Sign-in uses `current-password` so the browser offers saved credentials; sign-up uses `new-password` so the browser offers to save the new credential.
