# Yatırım Rehberi / Eğitim İçeriği

Kullanıcıya dönük yatırım eğitimi ve felsefesi. Mühendislik notu değil — planlı **Rehber** sekmesinin (hamburger nav) ve AI etkileşimlerinin felsefe kaynağı.

## Bu klasördeki dosyalar

| Dosya | Ne içerir |
|-------|-----------|
| [investment-guide.md](investment-guide.md) | Yatırım felsefesi + 20-kriter fundamental checklist; portföy yönetimi temelleri |

## Nasıl kullanılır

- **Rehber sekmesi** içeriği üretilirken → bu dosya kaynak (ROADMAP "Öğrenme & Eğitim").
- **Fundamental checklist gruplaması** (`FUND_GROUPS`) hizalanırken → Part 5 başlıkları referans (ROADMAP backlog).
- **AI system prompt** felsefesi → `Investment Guide → Claude system prompt` backlog item'ı bu dosyayı `SYSTEM_PROMPT` constant'a dönüştürmeyi planlar.
- İçerik kullanıcı-onaylı eğitim materyali; teknik karar notu değil — değişiklik için kullanıcıya danış.
